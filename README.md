# webui

A minimal, security-conscious toolkit for server-rendered web user interfaces in Go.

Pages are typed [chord](https://github.com/protolambda/chord) element trees, styled by
Bootstrap 5.3 CSS and made interactive by htmx 2, without application JavaScript and
without Bootstrap's JavaScript.

Work in progress.
